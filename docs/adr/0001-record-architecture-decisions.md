# 0001 — Record architecture decisions

- Status: accepted
- Date: 2026-10-14

## Context

The spec (`docs/navarch-especificacao.md` §19) lists open decisions and asks for each to be recorded as an ADR once decided.

## Decision

Architecture decisions are recorded in `docs/adr/NNNN-title.md`, in English, with Status, Date, Context, Decision and Consequences. An ADR that changes the architecture is merged together with the matching spec update. Superseded ADRs stay in place with `Status: superseded by NNNN`.

## Consequences

Decisions are reviewable in pull requests and traceable from the spec by number.
